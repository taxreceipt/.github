# tax.receipt

**We connect. We verify.**

tax.receipt VERIFY is an independent check that the receipt, the payment and the provider behind an insurance claim are real, before the insurer pays.

**Three records. Three checks. One grade.**

- Built in Auckland, New Zealand, for health insurance claims first.
- VERIFY does one job: it verifies the receipt. The insurer keeps every decision.
- Our source code is private. This page is our public home on GitHub.

Website: [www.taxreceipt.io](https://www.taxreceipt.io) · Contact: hello@taxreceipt.io

## Reporting a security concern

If you believe you have found a security problem in anything run by tax.receipt, please email **hello@taxreceipt.io** with "Security" in the subject line. Please do not post details publicly. See our [security policy](https://github.com/taxreceipt/.github/blob/main/SECURITY.md).
